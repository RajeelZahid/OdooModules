Debug Mode Manager

Overview

This module provides extended capabilities for debugging management in Odoo. By introducing two new fields in the Users, it enables administrators to assign specific debug preferences and empower users with the ability to override debugging via URL parameters.
The field offers seven tailored debug options, providing granular control over user behavior. With the addition of, users can now force specific debug modes through the URL parameter, giving unparalleled flexibility during development or troubleshooting.

Key Features

  • Two new fields: Default Debug Mode and Allow Force Debug on the Users.
  • Seven selectable debug modes tailored for various workflows.
  • URL-based debug forcing with force_debug_mode parameter.
  • Enhanced productivity and streamlined debugging for development teams.

Debug Mode Options

  • Use from URL (No Force): Allows the user to toggle debug mode manually through the URL parameter. No mode is enforced by default.
  • Always Debug: Permanently enables debug mode (debug=1) for the user, making all debugging tools available at all times.
  • Assets: Activates the "debug with assets" mode, which disables minified and bundled assets for easier debugging of JavaScript, CSS, and other resources.
  • Tests: Turns on "debug with tests" mode, enabling automated testing tools and advanced features for development scenarios.
  • Disable-T-Cache: Disables template caching, ensuring real-time updates to views and templates during testing and development.
  • Multiple: Allows multiple debug modes (e.g., Assets and Tests) to be active simultaneously for flexible and comprehensive debugging.
  • Disallow Always: Restricts the user entirely from enabling any debug mode, ensuring no accidental or unauthorized debugging access.
