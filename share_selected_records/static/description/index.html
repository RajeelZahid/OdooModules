Share Selected Records

Overview

This Odoo module revolutionizes how users interact with records by enabling seamless sharing. Users can effortlessly select multiple records and generate a unique, shareable link with a single click. This link is automatically copied to the clipboard for immediate use. Designed to streamline collaboration and enhance accessibility, the module is perfect for businesses looking to share record data efficiently within teams. The intuitive button feature ensures minimal learning curve while maximizing productivity.

Key Features

  • Select records and copy shareable link with single click
  • Paste and send to team
  • View records with ease using the link

How to use

Share Selected Records | Compatible with Odoo Community, Enterprise, and Odoo.sh
