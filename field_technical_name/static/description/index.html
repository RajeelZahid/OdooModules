Overview

Tired of hovering over fields just to see their technical names?

Introducing the Field Technical Name module, a productivity-enhancing tool for Odoo developers and functional users. This module displays the technical field name directly next to the field label in form and list views.

No more memorizing. With this module, each field comes with a dedicated copy button in form view, making it easier than ever to work with technical field references.

Key Features

  • Instant Technical Field Name Visibility: Displays the technical name of each field right after the field label — no hover required.
  • One-Click Copy Button: Easily copy the technical field name with a single click using the built-in button.
  • Improved Workflow for Developers: Save time during debugging, customization, or configuration.
  • Seamless Integration: Works out of the box with standard Odoo views without requiring any manual setup.
  • Non-Intrusive UI Enhancement: Enhances the interface without disrupting existing design or behavior.

How to Use

Enable the debug mode

List View Compatibility

Please note that the integration may not work with every list and one2many (O2M) list view by default. To enable it manually, navigate to views/list/list_render.xml and uncomment the relevant section.

Example: To enable the feature in the Invoice list view, uncomment the line related to account.FileUploadListRenderer.
